How It Works

A transparent, closed-loop resolution process from submission to student sign-off.

1

1. Report

Select category, specify building and room, attach optional photo evidence, and submit.

2

2. Assign & Track

The ticket routes to the appropriate department. Watch real-time timeline updates on your dashboard.

3

3. Resolve & Rate

Staff completes the repair and provides proof. You receive a notification and rate the resolution quality.

Enterprise Institutional Security Standards

Engineered with multi-layered defenses to safeguard student privacy and campus data integrity.

Strict Injection Defenses

All database transactions utilize PDO prepared statements with strict emulation disabled, preventing SQL injection.

Bcrypt Password Hashing

Credentials protected with adaptive cost-factored Bcrypt hashes. No plaintext passwords or weak MD5/SHA1 hashing.

Hardened File Uploads

Uploaded images undergo MIME validation, strict extension whitelisting, randomized hash storage, and script execution blocking.

CVE-2024-4577 Hardening

Hardened against Windows PHP CGI argument injection attacks with active query string sanitization and modern CSP headers.
